# Changelog

## 0.1.0

- Independent Rust implementation of DrugZ with paired and unpaired analysis.
- Finite input checks, locked dependencies, stored reference tests and per-file safe writing.
- Eight output-formatting workers by default; scientific calculations remain single-threaded.
- Source use is qualified for macOS ARM64. No binary distribution or tagged release is provided.
- Includes the user manual, manuscript PDF and synthetic teaching examples.
